# 002 — Grilling: make the assumptions clear

**Status:** done (2026-10-13)
**Started:** 2026-10-13

## Goal

Turn the user's request into clear, agreed decisions before we build anything. Questions are asked in batches. Big or important questions are asked one at a time.

## Outputs

- `/CONTEXT.md` — the glossary, updated as each term is agreed.
- `docs/adr/` — only for decisions that are hard to reverse, surprising, and a real trade-off.
- `tasks/decisions-log.md` — each batch of questions, the answers, and what follows from them.

## Exit criteria

Every branch of the design is agreed: analysis, playlist definition, pruning, DJ mix, and the app setup.
